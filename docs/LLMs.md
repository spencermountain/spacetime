# Spacetime

Spacetime is a zero-dependency JavaScript library for dates and timezones,
with bundled timezone rules and a mostly immutable API.

Start with the [usage guide](./README.md) for examples, essential conventions,
and topic navigation. Use the [API reference](./API.md) for method signatures
and return values, and [edge cases](./edge-cases.md) for DST, clamping, invalid
inputs, and mutation exceptions.

For native Temporal inputs or the experimental `spacetime/temporal` entry,
see [Temporal](./Temporal.md).
